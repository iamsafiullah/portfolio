# Safi Ullah — Portfolio

Modern, responsive portfolio website (static HTML/CSS/JS) built for easy Netlify deployment.

## Deploy to Netlify

1. Drag & drop this folder into Netlify (https://app.netlify.com/drop), OR
2. Connect the repository and set:
   - Build command: (leave empty)
   - Publish directory: `.`

No build step required.

## Structure

- `index.html` — main page
- `styles.css` — styling
- `script.js` — interactions & animations
- `assets/images` — proof-of-work screenshots
- `assets/reports` — SEO reports & CV (PDF)
- `netlify.toml` — Netlify config & headers
